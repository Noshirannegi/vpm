おもかげ（Omokage）

VRChat の表情ツール。表情づくり・ハンドサインへの割り当て・表情ごとのまばたき・メニュー生成を 1 つの画面で。

1. VCC にリポジトリを追加する

VCC に追加

ボタンが効かないときは、VCC の Settings → Packages → Add Repository に次を貼り付けてください。
https://noshirannegi.github.io/vpm/index.json

2. Modular Avatar のリポジトリも追加する

おもかげは Modular Avatar を使います。まだなら Modular Avatar のページの「Add to VCC」から追加してください。

3. プロジェクトに入れる

  1. VCC でプロジェクトの「Manage Project」を開く
  2. 「おもかげ（Omokage）」の ＋ を押す（Modular Avatar も一緒に入ります）
  3. Unity のメニュー「おもかげ → おもかげ」で画面が開きます

旧版（v0.9 系・.unitypackage で入れたもの）を使っていた人は、先に Unity を閉じて Packages/jp.noshi.omokage フォルダを消してください。

おもかげ Live

コントローラーで目と口を動かす「Live」には、PC で動かす Omokage Companion（BOOTH・有料）が要ります。
BOOTH のショップ

おもかげは MIT ライセンスです。不具合の報告は、おもかげの「不具合報告用の情報をまとめる」で作った zip を添えて、BOOTH のメッセージでお送りください。
